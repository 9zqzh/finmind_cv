## 1. 项目概述

### 1.1 项目背景

"数智金院 FinMind" 是面向 **广东金融学院** 在校学生的智慧校园移动端助手应用。项目旨在整合校园教务查询、生活服务、AI 智能问答及知识库检索等核心功能，为学生提供一站式的数字化校园体验。

### 1.2 产品定位

| 维度 | 说明 |
|------|------|
| **应用名称** | 数智金院 FinMind |
| **目标用户** | 广东金融学院在校学生 |
| **应用平台** | iOS / Android (跨平台开发，采用 React Native 或 Flutter) |
| **现有技术栈参考** | Web 端采用 React + TypeScript + Ant Design + FastAPI 后端 |
| **核心价值** | 校园信息聚合、AI 智能助手、知识库检索、生活服务入口 |

### 1.3 功能全景

应用采用 **底部四标签导航** 架构，包含以下四大核心模块：

| 序号 | 模块 | 说明 |
|------|------|------|
| 1 | 首页 | 今日课表、待办清单、功能大厅入口 |
| 2 | AI 对话 | 智能问答、流式响应、结构化结果展示 |
| 3 | 知识库 | 文档检索、文件浏览、RAG 混合搜索 |
| 4 | 我的 | 个人信息、学术信息、系统设置 |

## 2. 整体架构与技术栈

### 2.1 移动端技术选型

| 层级 | 技术方案 |
|------|----------|
| **UI 框架** | React Native (推荐，与 Web 端 React 技术栈一致) 或 Flutter |
| **状态管理** | Zustand / Redux Toolkit (React Native) 或 Riverpod (Flutter) |
| **网络层** | Axios + SSE 客户端 (AI 对话流式传输) |
| **本地存储** | AsyncStorage / MMKV (轻量数据) + SQLite (离线缓存) |
| **推送服务** | FCM (Android) + APNs (iOS) |
| **图片识别** | 系统相机 API + OCR 服务 (待办拍照导入) |

### 2.2 后端对接

移动端复用现有 Web 端 FastAPI 后端，新增移动端适配接口。所有接口统一使用 JWT 鉴权，数据格式为 JSON。

### 2.3 页面结构总览

```
App
├── AuthScreen (登录页)
└── MainTabNavigator (底部标签导航)
    ├── HomeScreen (首页)
    │   ├── ScheduleDetailScreen (课表详情)
    │   └── FunctionSubPages (功能大厅子页面)
    ├── AIChatScreen (AI 对话)
    │   └── ChatHistoryScreen (历史对话)
    ├── KnowledgeScreen (知识库)
    │   └── FileBrowserScreen (文件浏览)
    └── ProfileScreen (我的)
        └── SettingsSubPages (设置子页面)
```

## 3. 底部导航栏

### 3.1 基本规格

| 属性 | 规格 |
|------|------|
| **标签数量** | 4 个 |
| **位置** | 屏幕底部固定定位 (fixed) |
| **高度** | 56px + iOS Safe Area 底部内边距 |
| **背景色** | 纯白 (#ffffff)，上方带 1px 分割线 (#e5e7eb) |
| **标签项** | 图标 (24px) + 文字标签 (10-11px) |

### 3.2 标签定义

| 序号 | 标签名称 | 图标 | 默认页面 |
|------|----------|------|----------|
| 1 | 首页 | 房屋图标 | HomeScreen |
| 2 | AI 对话 | 对话气泡图标 | AIChatScreen |
| 3 | 知识库 | 书籍/文件夹图标 | KnowledgeScreen |
| 4 | 我的 | 用户头像图标 | ProfileScreen |

- **选中态**: 图标与文字颜色切换为主题蓝色 (#1677ff)，顶部显示 2px 高度的蓝色指示条
- **未选中态**: 图标与文字颜色为灰色 (#98a2b3)
- **切换动画**: 无页面切换动画，直接跳转
- **iOS 适配**: 底部安全区域 (Safe Area Inset) 自动适配，防止内容被 Home Indicator 遮挡
- **Android 适配**: 支持手势导航栏与物理按键两种模式

#### 4.3.4 拍照识别功能 (OCR)

**核心流程**:

1. 用户点击相机图标按钮
2. 调起系统相机或从相册选择图片
3. 将图片发送至后端 OCR 服务
4. 识别结果以列表形式展示，用户勾选确认
5. 确认后的条目自动添加至待办清单

**支持识别的内容**:
- 手写/打印的待办事项文字
- 课表截图中的课程信息
- 通知/公告中的关键任务

#### 4.3.5 数据逻辑

- 待办数据本地持久化存储 (SQLite/AsyncStorage)
- 支持拖拽排序
- 已完成任务自动移至底部
- 次日未完成的任务保留并标记为 "已逾期" (橙色 #d46b08)

### 5.7 SSE 流式响应

#### 5.7.1 技术方案

- 使用 **Server-Sent Events (SSE)** 协议实现流式传输
- 客户端通过 `EventSource` 或兼容的 HTTP 流读取方式接收数据
- 请求方式: `POST /api/chat/stream`
- 请求体: `{ "message": "用户消息", "conversation_id": "会话ID" }`

#### 5.7.2 流式展示逻辑

| 阶段 | 表现 |
|------|------|
| **等待响应** | AI 气泡显示 "正在思考..." + 三点加载动画 |
| **思考过程** | 思考面板展开，步骤依次出现 |
| **文本输出** | 文字逐字/逐块出现，带光标闪烁效果 |
| **结构化数据** | 文本输出完毕后，结果卡片淡入展示 |
| **响应结束** | 光标消失，显示消息时间戳 |
| **响应异常** | 显示 "网络异常，请重试" 红色提示 + 重试按钮 |

## 11. 交互说明

### 11.1 全局交互规范

| 场景 | 规范 |
|------|------|
| **页面加载** | 显示骨架屏 (Skeleton) 占位，数据加载完成后淡入切换 |
| **空状态** | 各列表页面提供空状态插图 + 引导文案 |
| **错误状态** | 网络错误时显示重试按钮 + 错误说明 |
| **下拉刷新** | 所有列表页支持下拉刷新 (Pull to Refresh) |
| **上拉加载** | 分页列表支持上拉加载更多 (Infinite Scroll) |
| **Toast 提示** | 操作反馈使用轻量 Toast, 显示 2 秒后自动消失 |
| **确认弹窗** | 破坏性操作 (删除、退出) 需二次确认 |
| **手势返回** | iOS 支持左滑返回上一页 |

### 11.2 待办清单交互

| 操作 | 行为 |
|------|------|
| **手动输入** | 输入文字后点击发送或按回车，新任务添加至列表底部，优先级默认 "低" |
| **拍照导入** | 点击相机按钮 -> 拍照/选图 -> OCR 识别 -> 结果确认 -> 批量添加 |
| **完成任务** | 点击复选框，该任务标记完成，文本添加删除线，移至列表底部 |
| **删除任务** | 左滑显示红色删除按钮，点击删除 |
| **修改优先级** | 点击优先级标签，弹出选择器 (高/中/低) |
| **拖拽排序** | 长按任务项进入拖拽模式，自由调整顺序 |

### 11.3 功能大厅交互

| 行为 | 说明 |
|------|------|
| **页面跳转** | 大部分功能项点击后跳转至独立子页面 |
| **AI 对话集成** | 部分功能 (如意见反馈) 可在 AI 对话中以对话形式完成 |
| **动态配置** | 功能项列表可通过后端配置动态调整 (显示/隐藏/排序) |
| **角标提示** | 部分功能项可显示未读角标 (红色圆点或数字) |

### 11.4 AI 对话交互

| 场景 | 行为 |
|------|------|
| **发送消息** | 输入文字后点击发送按钮或按键盘回车；消息立即出现在用户气泡中 |
| **流式响应** | AI 回复逐字显示，思考过程可折叠/展开 |
| **结果卡片** | 结构化数据 (课表/成绩) 以卡片形式嵌入消息流 |
| **消息操作** | 长按 AI 消息: 复制、重新生成 |
| **自动滚动** | 新消息到来时自动滚动到底部；用户手动滚动时暂停自动滚动 |
| **网络异常** | SSE 中断时显示错误提示 + 重试按钮 |

### 11.5 主题切换交互

| 操作 | 行为 |
|------|------|
| **切换方式** | "我的" 页面 -> 页面主题 -> Toggle 开关 |
| **过渡动画** | 切换时使用淡入淡出过渡 (300ms) |
| **持久化** | 用户选择持久化存储，下次启动保持上次选择 |
| **跟随系统** | 可选 "跟随系统" 模式，自动适配系统深浅色 |

## 12. 非功能性需求

### 12.1 性能要求

| 指标 | 标准 |
|------|------|
| **启动时间** | 冷启动 < 3 秒 (主流设备) |
| **页面切换** | < 300ms |
| **列表滚动** | 60 FPS, 无卡顿 |
| **API 响应** | 普通接口 < 1 秒, AI 首 Token < 2 秒 |
| **内存占用** | 运行内存 < 300MB |

### 12.2 兼容性要求

| 平台 | 最低版本 |
|------|----------|
| **iOS** | iOS 14.0+ |
| **Android** | Android 8.0 (API 26)+ |
| **屏幕适配** | 4.7 英寸 ~ 6.9 英寸，支持刘海屏/挖孔屏 |

### 12.3 安全要求

| 维度 | 要求 |
|------|------|
| **传输加密** | 全链路 HTTPS |
| **Token 存储** | 使用系统安全存储 (Keychain / Keystore) |
| **敏感数据** | 密码加密传输，不在本地存储明文密码 |
| **证书校验** | 生产环境启用 SSL Pinning |
| **代码混淆** | Android ProGuard / iOS 编译优化 |

### 12.4 可用性要求

| 维度 | 要求 |
|------|------|
| **离线支持** | 课表、待办清单支持离线查看 (本地缓存) |
| **降级策略** | 后端服务不可用时显示友好提示，不白屏 |
| **无障碍** | 支持系统字体大小调节，关键操作提供触觉反馈 |

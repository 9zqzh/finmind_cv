# 团队运行与向量检索指南

> 统一配置模板为仓库根目录 `.env.example`；真实 `.env` 和密钥不得提交。

## 1. 推荐：Docker 完整运行

首次初始化：

```powershell
Copy-Item .env.example .env
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

在 `.env` 中填写 `POSTGRES_PASSWORD` 和生成的 `SESSION_ENCRYPTION_KEYS`；需要 AI 对话时再填写 `DEEPSEEK_API_KEY`。随后运行：

```powershell
docker compose up --build -d
```

访问 `http://localhost:8080`。默认启动 Nginx 前端、FastAPI 后端和 PostgreSQL，知识库使用关键词检索。

## 2. Docker 向量模式

在 `.env` 中配置：

```dotenv
KNOWLEDGE_RETRIEVAL_MODE=auto
CHROMA_HOST=chroma
CHROMA_PORT=8000
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_API_KEY=自己的嵌入服务密钥
EMBEDDING_MODEL=实际可用的嵌入模型
```

启动带 Chroma 的 Profile：

```powershell
docker compose --profile vector up --build -d
docker compose --profile vector ps
```

Chroma 数据保存在命名卷 `finmind_chroma-data`。向量服务或嵌入接口异常时，后端会自动回退到关键词检索。

## 3. 非 Docker 本地开发

在仓库根目录执行：

```powershell
python -m venv backend\.venv
backend\.venv\Scripts\python -m pip install -e ".\backend[test]"
backend\.venv\Scripts\python -m pip install -e .\packages\gduf-academic-api
Copy-Item .env.example .env
```

本地后端需要一个宿主机可访问的 PostgreSQL，并将 `DATABASE_URL` 指向它。启动后端：

```powershell
cd backend
.venv\Scripts\python -m app.start --reload --port 8000
```

另开终端启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

访问 `http://localhost:5173`，Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。

若本地后端需要连接 Docker Chroma，先运行 `docker compose --profile vector up -d chroma`，再设置：

```dotenv
CHROMA_HOST=127.0.0.1
CHROMA_PORT=8001
```

`CHROMA_HOST_PORT` 可调整宿主机端口。

# 团队本地运行与向量检索指南

> 适用对象：从 GitHub `main` 拉取项目的团队成员，以及协助开发的 AI。
> 本文是本地环境与知识库检索配置的优先参考；具体配置字段以 `back_end/backend/.env.example` 为准。

## 1. 先选择运行模式

| 模式 | 需要的额外条件 | 知识库行为 |
|---|---|---|
| 关键词模式 | 不需要 Docker、Chroma 或百炼 Key | 直接按关键词检索，可用于日常开发 |
| 向量模式 | Docker Desktop、Chroma、自己的百炼嵌入 Key | 使用 Chroma 向量相似度检索；异常时自动退回关键词 |

没有百炼 Key 不会导致项目无法运行。将 `KNOWLEDGE_RETRIEVAL_MODE` 设置为 `keyword`，即可明确使用关键词模式。

## 2. 共同安装步骤

```powershell
git pull origin main
cd back_end\backend
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[test]"
.venv\Scripts\python -m pip install -e ..\gduf-academic-api
Copy-Item .env.example .env
```

在 `.env` 至少填写自己的对话模型配置，例如 `DEEPSEEK_API_KEY`。`.env` 已被 Git 忽略，绝不能提交真实密钥。

启动后端：

```powershell
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

另开终端启动前端：

```powershell
cd front_end\web
npm ci
npm run dev
```

仓库默认前端地址为 `http://localhost:5173`，并代理到后端 `http://127.0.0.1:8000`。不要提交个人端口占用导致的 `vite.config.ts` 修改。

## 3. 关键词模式配置

在 `back_end/backend/.env` 写入：

```dotenv
KNOWLEDGE_RETRIEVAL_MODE=keyword
```

此模式无需 Chroma Docker，也无需填写任何 `EMBEDDING_*` 配置。知识库、资讯页面和 AI 工具 `search_knowledge` 都可以正常使用。

## 4. 向量模式配置

1. 安装并启动 Docker Desktop。
2. 在项目根目录启动 Chroma：

```powershell
docker compose -f docker-compose.chroma.yml up -d
```

3. 在自己的 `.env` 填写：

```dotenv
KNOWLEDGE_RETRIEVAL_MODE=auto
CHROMA_HOST=127.0.0.1
CHROMA_PORT=8001
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_API_KEY=自己的百炼API密钥
EMBEDDING_MODEL=qwen3.7-text-embedding
```

4. 重启后端。后端会自动读取已有 Markdown/JSON 资料，按既有切片规则写入本机 Chroma 索引。`back_end/backend/data/chroma/` 是本地生成数据，已被 Git 忽略，不需要在成员之间复制。

验证 Chroma 容器：

```powershell
docker compose -f docker-compose.chroma.yml ps
```

# 团队运行与向量检索指南

> 统一配置模板为仓库根目录 `.env.example`；真实 `.env` 和密钥不得提交。

## 1. 推荐：Docker 完整运行

首次初始化：

```powershell
Copy-Item .env.example .env
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

在 `.env` 中填写 `POSTGRES_PASSWORD` 和生成的 `SESSION_ENCRYPTION_KEYS`；需要 AI 对话时再填写 `DEEPSEEK_API_KEY`。随后运行：

```powershell
docker compose up --build -d
```

访问 `http://localhost:8080`。默认启动 Nginx 前端、FastAPI 后端和 PostgreSQL，知识库使用关键词检索（配置嵌入服务后自动升级为混合检索，见下节）。

## 2. Docker 向量模式

在 `.env` 中配置：

```dotenv
KNOWLEDGE_RETRIEVAL_MODE=auto
CHROMA_HOST=chroma
CHROMA_PORT=8000
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_API_KEY=自己的嵌入服务密钥
EMBEDDING_MODEL=实际可用的嵌入模型
```

启动带 Chroma 的 Profile：

```powershell
docker compose --profile vector up --build -d
docker compose --profile vector ps
```

Chroma 数据保存在命名卷 `finmind_chroma-data`。向量服务或嵌入接口异常时，后端会自动回退到关键词检索。

配置完整时启用**混合检索**：向量与关键词双路召回后按 RRF 融合排序，任一路径失败自动降级到另一路，单次故障不会永久关闭向量检索。相关调参变量（默认值）：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `KNOWLEDGE_VECTOR_MIN_SCORE` | `0.5` | 向量分数阈值，仅过滤语义明显无关项 |
| `KNOWLEDGE_VECTOR_CONFIDENCE_MIN` | `0.75` | 关键词零命中时向量结果的置信门槛，低于该值视为未检索到 |
| `KNOWLEDGE_VECTOR_TOP_K` | `20` | 混合检索时向量/关键词各自召回的候选数 |
| `EMBEDDING_RETRIES` | `2` | 嵌入请求失败时的指数退避重试次数 |

## 3. 非 Docker 本地开发

在仓库根目录执行：

```powershell
python -m venv backend\.venv
backend\.venv\Scripts\python -m pip install -e ".\backend[test]"
Copy-Item .env.example .env
```

本地后端需要一个宿主机可访问的 PostgreSQL，并将 `DATABASE_URL` 指向它。启动后端：

```powershell
cd backend
.venv\Scripts\python -m app.start --reload --port 8000
```

另开终端启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

访问 `http://localhost:5173`，Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。若本机 8000 端口被其他进程占用，后端改用其他端口（如 `--port 8001`）时，需同步修改 `frontend/vite.config.ts` 的代理 target。

若本地后端需要连接 Docker Chroma，先运行 `docker compose --profile vector up -d chroma`，再设置：

```dotenv
CHROMA_HOST=127.0.0.1
CHROMA_PORT=8001
```

`CHROMA_HOST_PORT` 可调整宿主机端口。

## 4. 可选地图查询（高德）

在 `.env` 中填写高德 Web 服务 Key（https://lbs.amap.com ，免费）：

```dotenv
AMAP_API_KEY=你的高德Web服务Key
# 可选：百度地图开放平台 Key，用于补充地点点评数与评分
BAIDU_MAP_API_KEY=
```

配置后即可在 AI 对话中使用：

- **周边地点查询**（如“学校周边有什么好吃的”）：返回名称、地址、电话、星级评分、人均消费、距中心距离，前端以卡片展示并附导航链接；
- **出行路线规划**：步行 / 驾车 / 骑行 / 公交，返回距离、预计耗时与导航链接；
- 默认起点为广东金融学院清远校区，可用 `AMAP_DEFAULT_ORIGIN` 修改、`AMAP_DEFAULT_LOCATION` 配置兜底坐标、`AMAP_SEARCH_RADIUS` 配置搜索半径（默认 5000 米）。

高德免费接口只提供星级评分与人均消费（无评论文本）；配置 `BAIDU_MAP_API_KEY` 后可补充地点点评数。未配置 Key 时 Agent 会如实提示，不影响其他功能。

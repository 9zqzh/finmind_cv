# 管理台审核操作指南（自进化草稿审核）

> 适用对象：项目管理员
> 功能入口：前端 `/admin` 页面（操作手册管理台）
> 作用：在浏览器中审核智能体自进化产出的手册草稿，无需在服务器上执行任何命令

---

## 一、首次使用前的服务器配置

### 1. 配置管理员令牌（必做）

项目部署到公网后，`ADMIN_TOKEN` 必须配置强随机串，否则管理接口等于裸奔。

登录云服务器，编辑项目根目录的 `.env`：

```bash
# 生成一个随机令牌（在服务器上执行）
openssl rand -hex 24
```

把生成的字符串填入 `.env`：

```dotenv
ADMIN_TOKEN=刚才生成的随机字符串
```

### 2. 确认定时自进化配置（可选调整）

```dotenv
EVOLUTION_SCHEDULE_ENABLED=true   # 定时自进化开关
EVOLUTION_INTERVAL_DAYS=7         # 每隔几天自动跑一次进化
EVOLUTION_RUN_HOUR=3              # 本地时间几点触发（低峰期）
```

### 3. 重启后端使配置生效

按你们部署方式重启服务（如 `docker compose restart` 或重启 systemd/uvicorn 进程）。

> 令牌与服务器 `.env` 中的 `ADMIN_TOKEN` 完全一致才能通过鉴权；
> 请记住这个令牌，打开管理台页面时需要输入。

---

## 二、打开管理台页面

### 步骤

1. 在任意设备（电脑或手机）的浏览器中打开：

   ```
   https://你的域名/admin
   ```

   例如部署地址是 `https://finmind.example.com`，则访问 `https://finmind.example.com/admin`。
   本地开发环境则是 `http://localhost:5173/admin`。

2. 页面顶部输入**管理员令牌**（即服务器 `.env` 里的 `ADMIN_TOKEN` 值）。
   - 令牌仅保存在当前浏览器标签页会话中，关闭标签页后需重新输入；
   - 令牌错误时，任何操作都会提示"管理员令牌无效"。

3. 页面包含三个页签：**待审草稿**、**手册列表**、**触发进化**。

> 该页面不挂在导航菜单里，只能直接输入地址访问，避免对学生暴露。

---

## 三、审核草稿（日常主要操作）

定时任务每 `EVOLUTION_INTERVAL_DAYS` 天自动分析一次高频提问，
把达标的问题簇总结成手册**草稿**（不会直接影响线上对话）。

1. 打开 **待审草稿** 页签，每张卡片是一条草稿：
   - **提问簇大小**：近期相似提问出现的次数，越大越值得沉淀；
   - **触发关键词**：命中这些关键词时手册会被触发，检查是否贴切；
   - **校验警告**（黄色提示）：模型生成的内容存在疑点，如引用了不存在的工具名，
     看到警告时建议谨慎，可拒绝；
   - 正文区域：手册的固定最优路径步骤，通读确认步骤正确、时间信息无误。

2. 判断后二选一：
   - **通过**：草稿立即转为正式手册（来源标记"自动生成"），
     用户后续提问命中关键词时即按此路径回答；
   - **拒绝**：二次确认后草稿被删除，同一问题簇在冷却期
     （`EVOLUTION_COOLDOWN_DAYS`，默认 14 天）内不会重复生成。

3. 审核原则建议：
   - 涉及具体时间、金额、流程步骤的，与官方通知核对后再通过；
   - 与既有人工手册内容冲突的，优先保留人工版本，拒绝草稿；
   - 拿不准的先拒绝，冷却期后如仍高频会再次生成。

## 四、查看手册列表

**手册列表** 页签展示全部生效中的手册：

- **来源**：`人工维护`（提交到仓库的正式手册）/ `自动生成`（审核通过的草稿）；
- **触发关键词** 与 **命中次数**：命中次数长期为 0 的手册可考虑清理或调整关键词；
- 展开行可查看手册正文。

> 手册文件支持**热加载**：直接编辑仓库中 `backend/data/playbooks/` 下的手册（或审核通过新草稿）后，无需重启服务，下一次匹配即生效。

---

## 五、手动触发进化

不想等定时任务时，可在 **触发进化** 页签点击"立即触发一次进化"：

- 过程需要调用大模型逐个总结高频簇，**可能耗时数分钟**，请勿重复点击；
- 完成后展示发现的簇数量与每条草稿的生成结果，点击"前往审核草稿"去审核；
- 定时任务与手动触发共用冷却期机制，不会重复生成相同草稿。

---

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示"管理员令牌无效" | 输入的令牌与服务器 `.env` 的 `ADMIN_TOKEN` 不一致，核对后重输 |
| 待审草稿始终为空 | 近期提问均已被现有手册覆盖，或处于冷却期；可先手动触发一次确认 |
| 触发进化超时 | 高频簇较多时模型总结耗时长，稍后回到"待审草稿"刷新即可，草稿已正常生成 |
| 页面打不开（404） | 前端未重新构建部署；确认已 `npm run build` 并更新了线上静态文件 |
| 所有接口报网络错误 | 后端未启动，或 Nginx 未把 `/api/admin/*` 转发到后端 |

# 管理后台操作指南

> 入口：`/admin`
> 鉴权：教务系统用户登录会话 + 学号管理员授权

## 首次配置

在项目根目录 `.env` 指定唯一初始管理员学号：

```dotenv
INITIAL_ADMIN_STUDENT_NUMBER=你的学号
```

修改后重启后端。未配置时应用仍可正常提供学生功能，但所有 `/api/admin/*` 接口均返回 403。

初始管理员使用自己的教务账号登录后访问 `https://你的域名/admin`。初始管理员由配置文件决定，不能在后台取消；更换配置后，旧学号只有在另有普通管理员授权时才能继续访问后台。

## 管理员授权

- 只有初始管理员能在“管理员”页签添加或取消普通管理员。
- 输入学号即可预授权，对方不需要提前登录；该学号首次成功登录后自动获得后台权限。
- 普通管理员可以使用用户审计、日志和操作手册功能，但不能继续分配管理员。

## 用户与对话审计

“最近登录用户”按最近登录时间倒序展示学号、最近活跃时间、有效会话状态和对话数量。点击“查看对话”可浏览该用户的对话列表及每轮用户消息和助手最终响应。

查看完整对话详情属于敏感管理行为，每次访问都会写入审计日志。后台不会展示内部模型消息，也不会展示密码、验证码、Cookie 或会话令牌。

## 审计日志

“审计日志”记录：

- 登录成功或失败、退出；
- 添加或取消管理员；
- 查看用户对话详情；
- 触发操作手册进化、通过或拒绝草稿。

日志可按事件类型和操作者/目标学号筛选，并保存事件结果、时间、IP、User-Agent 和非敏感元数据。登录失败会保留学号和错误码，但不会保存密码、验证码或请求体。

## 操作手册审核

- “待审草稿”：检查关键词、问题簇大小、校验警告和正文后选择通过或拒绝。
- “手册列表”：查看全部生效手册、来源、关键词、命中次数和正文。
- “触发进化”：立即分析近期高频问题并生成待审草稿；调用模型可能耗时数分钟，请勿重复点击。

通过的草稿会立即成为正式手册；拒绝的草稿会被删除，并按 `EVOLUTION_COOLDOWN_DAYS` 进入冷却期。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 登录后提示无管理权限 | 确认登录学号与初始管理员配置或后台预授权学号完全一致 |
| 所有管理员都返回 403 | 检查 `INITIAL_ADMIN_STUDENT_NUMBER` 是否为空，并重启后端 |
| 新管理员无法进入 | 确认预授权的是对方实际教务登录学号，让对方重新登录刷新角色 |
| 页面 404 | 重新构建并部署前端静态文件 |
| 管理接口网络错误 | 检查后端状态以及 Nginx 对 `/api/admin/*` 的转发 |

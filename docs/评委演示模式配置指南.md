# 评委演示模式配置指南（免登录体验）

> 适用场景：比赛评审、路演展示等需要**访客打开平台即直接进入主界面**、无需注册登录即可体验真实功能的场合。
> 适用读者：项目管理员（部署负责人）
> 前置条件：已完成部署并配置 `INITIAL_ADMIN_STUDENT_NUMBER`（管理后台可用）

---

## 一、原理

演示模式（`DEMO_MODE=true`）下，后端会把数据库中的**共享教务会话**自动提供给所有未携带登录令牌的访客：

- 评委打开域名 → 无令牌 → 后端自动复用共享会话 → 直接进入主界面（跳过登录页）；
- 可体验**真实个人数据**（课表、成绩、培养方案等，均来自共享账号），也可正常使用 AI 对话、知识库、地图等全部功能；
- 管理接口不受影响：共享会话不视为管理员身份，评委游客无法访问 `/admin` 后台；
- 共享会话随使用自动续期（同正常登录会话的 TTL 滚动机制），长期有效。

## 二、部署配置

在服务器项目根目录 `.env` 中：

```dotenv
# 管理后台初始管理员学号（必填，否则管理接口全部 403）
INITIAL_ADMIN_STUDENT_NUMBER=你的学号
# 开启评委演示模式
DEMO_MODE=true
```

修改后重启后端（`docker compose restart backend` 或重启 uvicorn 进程）。

> 未配置共享会话时，开启 `DEMO_MODE` 只会在登录状态接口返回 `demo_mode` 标志，访客仍会看到登录页；配置共享会话后免登录立即生效。

## 三、配置共享会话（一次配置，长期有效）

1. 用**共享账号**（建议专门准备一个用于演示的教务账号）在浏览器中正常登录平台；
2. 打开开发者工具（F12）→ **Network** 面板，刷新页面，点击任意 `/api/*` 请求，在 **请求头** 中复制 `X-Session-Token` 的值（一长串随机字符）；
3. 用你自己的管理员账号登录平台，打开 `/admin` → **评委演示** 页签；
4. 在"配置共享会话"输入框中粘贴上一步复制的令牌，点击 **设为共享会话**；
5. 页面上方显示共享账号与最近更新时间即配置成功。

验证：用无痕窗口（或另一台设备）打开平台域名，应直接进入主界面且无需登录。

## 四、自动恢复（可选，推荐比赛场景开启）

教务系统会话时效较短（通常 1 天内失效），为了让评委体验期间**始终可用、无需人工干预**，可启用守护任务：后端周期性检查共享会话有效性，失效时**自动重新登录共享账号并恢复**（本地 OCR 识别验证码，全程无人值守）。

### 1. 安装 OCR 依赖（服务器）

```bash
cd backend
.venv/bin/pip install -e ".[demo]"   # 安装 ddddocr（约 100MB，离线运行）
```

### 2. 配置共享账号凭据（服务器 .env）

```dotenv
# 共享账号凭据：仅用于守护任务失效时自动重登，只存服务器 .env（不入仓库）
DEMO_ACCOUNT_STUDENT_NUMBER=共享账号学号
DEMO_ACCOUNT_PASSWORD=共享账号密码
# 检查间隔（分钟，默认 30）；OCR 识别失败重试次数（默认 3）
DEMO_GUARD_INTERVAL_MINUTES=30
DEMO_RELOGIN_MAX_ATTEMPTS=3
```

### 3. 重启后端生效

重启后守护任务随服务启动：每 `DEMO_GUARD_INTERVAL_MINUTES` 分钟验证一次共享会话，失效即自动重登并更新共享会话（管理台"评委演示"页签可查看守护状态：上次检查、自动恢复次数、错误信息）。

> 未安装 ddddocr 或未配置凭据时，守护任务自动降级为"仅检测 + 状态提示"，不会影响现有功能。

## 五、维护

| 场景 | 处理 |
|---|---|
| 共享会话失效（教务系统侧过期、改密码等） | 已开启自动恢复时守护任务会自动重登，无需处理；否则用共享账号重新登录，按第三节重新设置令牌即可 |
| 临时关闭免登录 | 管理台“评委演示”页签点击 **清除共享会话**（无需改配置重启） |
| 彻底关闭演示模式 | 将 `.env` 中 `DEMO_MODE` 改回 `false` 并重启后端 |
| 更换共享账号 | 重新设置令牌即覆盖旧配置；自动恢复账号需同步修改 `DEMO_ACCOUNT_*` |

## 六、安全说明

- 共享会话令牌以加密形式存于数据库（与登录 Cookie 同级加密），接口不返回令牌本身；
- 演示模式下访客身份等同共享账号（能看到该账号的课表/成绩等个人数据），请使用专门准备的演示账号，**不要使用真实个人账号**；
- 评委体验时**退出登录按钮自动隐藏**，避免误操作销毁共享会话；后端同时拒绝从演示回退会话发起登出；
- 所有"设置/清除共享会话"操作均写入审计日志（事件 `admin.demo_session.set` / `admin.demo_session.clear`）；
- 管理台"评委演示"页签仅初始管理员（超级管理员）可修改配置，普通管理员只可查看；
- 自动恢复使用的共享账号密码仅存于服务器 `.env`（已 gitignore），**不进入代码与仓库**；若服务器被多人共用，请限制 `.env` 文件权限。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 开启 DEMO_MODE 后访客仍看到登录页 | 未配置共享会话：按第三节在管理台设置 |
| 设置令牌时报"令牌无效或会话未持久化登录" | 确认粘贴的是**登录成功之后**的 `X-Session-Token`（验证码阶段令牌不可用），且该会话未过期 |
| 评委使用一段时间后回到登录页 | 共享会话被教务系统判定过期（如账号异地登录、改密），重新配置即可 |
| 管理台"评委演示"页签不可见 | 当前账号不是管理员；配置修改仅初始管理员可见 |
